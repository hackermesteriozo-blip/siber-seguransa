Sobre o ANON CYBERSEC PRO

Projeto de interface para apoiar aprendizado e auditoria defensiva. A versão Python fornece ferramentas básicas de DNS, cabeçalhos HTTP, TLS, integridade de arquivos e verificação TCP limitada.

Para disponibilizar resultados reais pela web, implemente um backend seguro, autenticação, autorização por ativo e limites de uso. Não exponha comandos de sistema arbitrários ao navegador.
